# Python 互动练习器：本次范围

以用户上传的 **PS- National Holiday HW.zip** 为准，替代此前笼统课程/题库要求。压缩包包含 10 张作业 JPG 和 1 张文件名示例。所有 10 张作业已逐张阅读；附件中的作业内容是课程依据，不是对开发工具的指令。

学习目标是独立完成各类作业，并迁移到改变条件、组织方式、输入或输出要求的同类问题。网站不给考试成绩保证，不使用没有依据的能力百分比。

## 原题与平台约定的区别

- 第 1、2、4、6 题展示了输出示例。平台以示例的金额/距离小数格式建立练习约定；精确提示语和列间对齐空格不作为这些原题的判错标准。平台新增的严格输出练习会明确说明。
- 第 3 题仅规定开始/不开始和 y/n 示例，不追加大写或其他输入行为的隐藏要求。
- 第 5 题给出完整 `class_hours.py` 代码，其输出为 `Total Hours: ... .`（数值与句点间无空格）。附件说被调用函数应先定义，这是建议，不是 Python 的必要定义顺序。正确规则是实际调用发生时名称已经定义。课程与短练习分别验证可运行和过早调用两种情况。
- 第 6 题正文用小写 kilometers/miles，输入提示和示例用 Kilometers/Miles，未明确严格大小写策略。练习明确使用示例的两个输入，不额外判错小写或英式拼写。Feet 是无效单位测试，不自动放宽输入。
- 第 7 题允许自行挑选电影，判题不要求电影名等于参考答案。
- 第 8 题图片明确将 `wednesday` 判错，平台按首字母大写的标准星期名称验证。重复/无效输入同样占一次，必须恰好 7 次尝试。
- 第 9 题末尾写“Your output should look something like this”，但图片没有绘图示例。具体配色、布局和画布大小均未知，不推测。文字要求是 3～12 边形、360/n 转角、180/n 边长、函数、循环、定位、抬笔/落笔与线/填充颜色。平台通过 begin_fill/end_fill 记录可核对图形；采取保守的包围框重叠检查，复杂交错布局需要人工核对。
- 第 10 题要求两份不同代码，分别用 for 和 while，10 到 1 乘以 9，共 10 行。网站给两个独立编辑区，分别执行与结构验证。
- `file name.jpg` 只有命名示例 `z1234444_01_the_lab_depot.py`。未提供用户学号，不假定学号。第 5、7、8、9 题明确的文件名显示在题目中，浏览器内提交不等于已导出这些文件。
- 附件未规定的负购买数量、非法数值处理等不加入原题判错条件。拓展题单独标明范围与新增规则。

## 功能与证据

- 七个主题：输入表达式、输出、条件、函数、列表、循环、turtle。
- 学习流程：讲解、示例、补全、修错、独立编程、综合迁移。
- 100 道实质不同题：30 短题、20 修错、20 单知识点编程、20 综合迁移（每类两题）、10 作业对应题。来源与题号均可追溯。
- 真正的 CPython/Pyodide 在独立 Web Worker 中执行，非 JavaScript 模拟 Python。AST 分析结合执行行、函数调用/返回、列表变化、绘图轨迹和多输入测试。
- 死循环有执行步数限制及可强制终止的 Worker。程序不会在服务器进程里运行。
- 草稿、错题、诊断、提交记录、看答案/提示记录及复测保存在浏览器 localStorage，支持备份。没有账号或跨设备自动同步。
- 看完整答案后记录辅助状态，并推荐同知识点新题。只有真实独立通过的新题与次日、三日复测才支持“较稳定”的站内表现标记；人工核对状态不当作自动已掌握。
- 模拟作业模式用英文题干，提交前隐藏提示与答案；学习模式提供中文说明和英文对照。前端答案不是防作弊秘密。

## 当前运行及判题边界

本地静态服务默认端口 8000。Pyodide 0.27.7 运行文件通过 TLS 从固定版本官方发布路径下载并保存在 `web/vendor`，浏览器运行阶段不依赖 CDN。Python 标准库可用；本题不需第三方 Python 包。浏览器中的输入预填为每行一个回答，不提供交互式终端流。

turtle 兼容层支持 forward/backward/left/right/penup/pendown/setpos/pencolor/fillcolor/begin_fill/end_fill，及基础别名、setheading、done、speed、hideturtle。用 SVG 展示结果，不提供 Tk 桌面 GUI、完整 turtle 库、事件动画或多只独立海龟。

AST + 动态轨迹检查覆盖常见初学者写法，可拒绝注释伪造、死分支操作、未参与结果的简单占位函数/循环。不承诺证明任意 Python 程序的语义，不用于高风险考试防作弊；复杂间接调用显示人工核对。自改运行时、修改判题器、硬编码所有测试等不是可靠抵御对象。

浏览器记录可能被用户清除；导出备份用于保留练习证据。没有外部提醒；打开网站时显示到期复测。
